# Workbench Methodology Baseline

本目录保存供顾问审核、供工程转译的方法论基线。它不是书籍摘要库，也不是自动评分规则库。

## 当前内容

- `schooling-by-design-v1/PACK.md`：学校变革外循环。用于检验使命、预期结果、证据、行动与调整机制是否连贯。
- `data-wise-v3/PACK.md`：成人实践内循环。用于从学习问题进入实践证据、行动与影响评估。
- `WORKBENCH-METHODOLOGY-CROSSWALK.md`：两套方法与五维全等框架、角色标准的职责分工。
- `AGENT-ASSESSMENT-PROTOCOL.md`：Agent 从 Evidence 到 Diagnosis Proposal 的统一判断协议。

## 权威顺序

```text
顾问批准的 Pack 版本
↓
Pack 中的 Criterion / Evidence Guidance / Guardrail
↓
带元数据过滤的本地检索
↓
原书章节或页码核验
```

原始 PDF 只用于本地核验和必要短摘录。Pack 必须人工审核后才能转换为机器可加载的 YAML/JSON；任何更新都创建新版本，不覆盖已经被正式判断引用的版本。

## 非目标

- 不把任一本书转化为单一总分；
- 不用检索相似度代替标准映射；
- 不把 Data Wise 用作教师绩效考核；
- 不让 Schooling by Design 取代本项目五维全等框架；
- 不保存或展示模型的隐藏推理过程。
