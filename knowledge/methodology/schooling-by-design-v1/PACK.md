# Schooling by Design Methodology Pack v1

**状态：Human-review baseline**  
**Workbench 角色：学校变革外循环 / 战略全等检验**  
**来源：Grant Wiggins & Jay McTighe, _Schooling by Design_（2007）**  
**本地源文件：`references/books/schooling-by-design-2007.pdf`**

## 1. 使用边界

本 Pack 用于判断学校是否从使命和长期学习结果出发，形成了可验证、可执行、可调整的变革设计。它提供逆向设计与全校改革的逻辑，不提供现成的学校分数，也不替代“五维全等模型”。

适用：学校使命、阶段目标、课程与评价、组织行动、资源配置、影响证据之间的连贯性分析。  
不适用：单次课堂评价、个人教师绩效评定、仅凭文本表述判断学校成熟度。

## 2. 核心构念

| Stable ID                 | 构念               | Workbench 评估问题                                 |
| ------------------------- | ------------------ | -------------------------------------------------- |
| `SBD.MISSION`             | 长期使命与学习结果 | 变革要让学习者最终获得什么，而不只是完成哪些活动？ |
| `SBD.BACKWARD_DESIGN`     | 从结果逆向设计     | 证据与行动是否由预期结果倒推，而非由现有项目拼接？ |
| `SBD.VISION_REALITY_GAP`  | 愿景—现实差距      | 当前基线与目标状态的差距是否被可信证据描述？       |
| `SBD.ACCEPTABLE_EVIDENCE` | 可接受证据         | 达成目标将出现哪些直接表现与间接指标？             |
| `SBD.ALIGNED_ACTION`      | 行动与条件对齐     | 策略、责任、资源、政策与时间安排是否共同指向目标？ |
| `SBD.PLAN_TO_ADJUST`      | 计划性调整         | 是否预先安排反馈、复盘和改变方案的机制？           |
| `SBD.HABITS`              | 组织习惯           | 逆向设计、证据使用和持续调整是否成为日常习惯？     |

## 3. 判断准则

### `SBD.C1.RESULT_CLARITY` 结果清晰度

- 支持证据：使命被转译为具体的学习者理解、能力、态度或长期表现；阶段目标可辨认。
- 相反证据：目标只写活动、口号、覆盖率或投入量；不同团队对成功含义不一致。
- 不足以判断：只有一份愿景文件，没有会议、课堂、课程或决策证据。

### `SBD.C2.EVIDENCE_BEFORE_ACTION` 证据先于行动

- 支持证据：行动前已定义成功表现、基线、进展指标与取证方式。
- 相反证据：先确定培训、课程或制度，再事后寻找能证明其有效的数据。
- 不足以判断：仅列 KPI，但无法说明它们与预期学习结果的关系。

### `SBD.C3.GAP_GROUNDED` 差距有证据支撑

- 支持证据：目标与现实使用可比证据描述，并承认数据限制或人群差异。
- 相反证据：以个别印象推断全校；只描述缺陷，不识别已有优势。
- 反例检查：是否存在相同资料可以支持的另一种差距解释？

### `SBD.C4.SYSTEM_ALIGNMENT` 系统对齐

- 支持证据：课程、评价、专业学习、领导行为、资源和政策相互强化。
- 相反证据：目标要求一种实践，但时间、考核、资源或领导信号奖励另一种实践。
- 边界：正式成熟度仍由“五维全等模型”的维度与阶段锚点裁定。

### `SBD.C5.FEEDBACK_ADJUSTMENT` 反馈与调整

- 支持证据：明确何时看什么证据、由谁解释、什么条件触发调整，并留有调整记录。
- 相反证据：只有期末验收；把偏差解释为执行不力而不检验原计划。
- 不足以判断：存在复盘会议，但没有证据表明决策因此改变。

## 4. Agent 输出要求

使用本 Pack 的 Diagnosis Proposal 必须说明：

1. 所评估的预期结果与当前阶段；
2. 观察事实与来源；
3. 目标—现实差距；
4. 关联的 Criterion ID；
5. 支持证据、相反证据与至少一个替代解释；
6. 建议行动及其预期影响证据；
7. 证据不足时的下一步观察，而不是强行定级。
