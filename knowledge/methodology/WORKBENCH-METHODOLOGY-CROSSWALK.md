# Workbench Methodology Crosswalk v1

## 1. 不是把四套框架混成一张评分表

Workbench 使用分层职责，而不是简单加权：

| 层                  | 回答的问题                                         | 正式职责             |
| ------------------- | -------------------------------------------------- | -------------------- |
| Schooling by Design | 整体变革是否由长期结果逆向设计，并可验证、可调整？ | 外循环与战略连贯性   |
| Data Wise           | 团队是否从学习者证据看见并改善成人实践？           | 内循环与证据探究纪律 |
| 五维全等框架        | 学校当前在哪个维度、哪个成熟阶段？                 | 项目正式状态模型     |
| 角色专业标准        | 校长、中层、教师出现了哪些阶段性行为？             | 角色行为锚点         |
| 顾问判断            | 当前证据是否足以采纳或修改建议？                   | 最终裁定             |

因此，书籍方法论产生“检查问题、证据要求和推论护栏”，不直接产生额外总分；正式阶段判断仍落在五维全等框架和角色行为锚点上。

## 2. 双循环关系

```text
外循环：使命 → 预期结果 → 可接受证据 → 系统行动 → 反馈调整
                         ↕
内循环：学习问题 → 实践证据 → 实践问题 → 小步行动 → 影响评估
```

外循环给内循环方向和成功标准；内循环提供真实课堂与团队证据，反过来修正外循环的目标、策略和条件。

## 3. 任务路由

| 用户任务                 | 主 Pack             | 必要联查                                |
| ------------------------ | ------------------- | --------------------------------------- |
| 评估学校整体变革设计     | Schooling by Design | 五维全等框架、阶段目标                  |
| 分析使命与行动脱节       | Schooling by Design | 领导/中层行为锚点                       |
| 分析教师团队能否看见实践 | Data Wise           | 教师行为锚点、学习者证据                |
| 形成课堂改进行动         | Data Wise           | 当前学校目标与资源条件                  |
| 判断学校成熟阶段         | 五维全等框架        | 两书只提供证据与推论检查                |
| 判断某角色行为成熟度     | 角色专业标准        | Data Wise 或 SBD 提供上下文，不代替锚点 |

## 4. 关键交叉检查

- 目标很清楚但课堂无变化：检查 `SBD.C4.SYSTEM_ALIGNMENT` 与 `DW.C2.PRACTICE_VISIBILITY`。
- 有大量教研活动但难证实影响：检查 `SBD.C2.EVIDENCE_BEFORE_ACTION` 与 `DW.C5.ACTION_IMPACT_COHERENCE`。
- 团队迅速提出培训方案：先检查 `DW.C1`、`DW.C3`，再看 `SBD.C3` 是否有可信差距基线。
- 个别课堂片段被推广为全校结论：触发 `DW.C4.INFERENCE_DISCIPLINE` 与 `SBD.C3.GAP_GROUNDED`。
- 制度目标与教师实际条件冲突：以五维全等框架定维度，用 `SBD.C4` 解释系统错位，并用 Data Wise 证据描述实践层后果。

## 5. 冲突与优先级

1. 事实证据优先于任何方法论标签；
2. 当前批准的五维阶段定义优先于书籍的泛化表述；
3. 角色判断必须引用对应角色锚点；
4. 多个方法论解释冲突时并列为替代假设，不由 Agent 擅自消解；
5. 证据不足或不可比时，输出下一步观察建议，不输出虚假精度；
6. 只有顾问可以批准正式 Diagnosis 与 State Commit。
