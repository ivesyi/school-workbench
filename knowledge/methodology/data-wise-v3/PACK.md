# Data Wise Third Edition Methodology Pack v1

**状态：Human-review baseline**  
**Workbench 角色：成人实践内循环 / 协作探究与影响验证**  
**来源：Kathryn Parker Boudett & Candice Bocala, _Data Wise, Third Edition_**  
**本地源文件：`references/books/data-wise-third-edition.pdf`**

## 1. 使用边界

本 Pack 用于帮助教师团队从学习者证据出发，看见成人实践与学习问题之间的关系，并通过行动和影响证据持续调整。它不是“教师是否有自知”的单项量表，也不是教师绩效评价工具。

适用：团队探究、实践证据、问题陈述、行动计划、影响评估。  
不适用：单凭一次听课给教师定级、把学生结果直接归因于单一教师、以合规检查代替专业学习。

## 3. 判断准则

### `DW.C1.LEARNING_PROBLEM_QUALITY` 学习问题质量

- 支持证据：连接优先问题；使用多类证据；同时识别学习者资产与重要差距；在学校可影响范围内；具体、可行动。
- 相反证据：问题描述成人不满意、课程覆盖或学生标签，却没有可观察的学习表现。
- 不足以判断：只有汇总成绩，无法区分任务、群体、体验或具体表现。

### `DW.C2.PRACTICE_VISIBILITY` 实践可见性

- 支持证据：团队结合产物、自述、观察或视频，关注教师、学习者、内容与任务之间实际发生的互动。
- 相反证据：只看教案中的“规定任务”，不看课堂中的“实际任务”；以自报替代全部实践证据。
- 取证原则：观察用于学习，不用于绩效评价；记录先保持客观、具体，再解释。

### `DW.C3.PROBLEM_OF_PRACTICE_QUALITY` 实践问题质量

- 支持证据：与学习问题相关；基于成人实践证据；承认教育者已有优势和下一步工作；在控制范围内；具体、可行动。
- 相反证据：归咎学生、家庭或不可控环境；直接跳到解决方案；用人格标签解释实践。
- 反例检查：同一实践是否在某些学习者、课程或条件下产生不同结果？

### `DW.C4.INFERENCE_DISCIPLINE` 推论纪律

- 支持证据：事实、解释、结论分开记录；团队能回到低推论、具体的描述，并主动寻找矛盾证据。
- 相反证据：从单个片段跳到能力、动机或因果判断；只进行避免分歧的“正向闲谈”。
- Agent 边界：不输出或保存隐藏思维链，只保存可审核的事实、短理由和引用。

### `DW.C5.ACTION_IMPACT_COHERENCE` 行动—影响连贯性

- 支持证据：行动计划明确谁、做什么、何时做；策略具有杠杆作用；影响计划同时观察学习者体验和表现，并有可测目标。
- 相反证据：只记录培训完成率、教师满意度或交付物；没有学习者层面的影响证据。
- 调整条件：预先说明什么证据会支持继续、修改或停止当前行动。

## 4. Agent 输出要求

使用本 Pack 的 Diagnosis Proposal 必须：

1. 先形成学习者中心问题，再讨论成人实践；
2. 标注使用了哪些实践证据及其局限；
3. 分开列出观察事实、解释和暂定判断；
4. 引用 Criterion ID，列出支持与相反证据；
5. 避免把相关性写成单因果；
6. 给出可执行的小步行动与影响取证计划；
7. 将诊断定位为团队学习建议，而非教师绩效结论。
