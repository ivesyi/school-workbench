# Reference Sources

本目录保存形成产品、Ontology 和 Methodology Pack 的原始资料。它们用于人工核验和受控本地检索，不直接成为评估规则，也不进入应用安装包。

| Path | 类型 | 用途 |
|---|---|---|
| `books/schooling-by-design-2007.pdf` | 书籍 | 学校变革逆向设计与外循环 |
| `books/data-wise-third-edition.pdf` | 书籍 | 协作探究、实践证据与影响评估 |
| `frameworks/heya-congruence-model-covers.pdf` | 框架材料 | 五维全等模型的项目状态框架 |
| `standards/australian-school-role-professional-standards.xlsx` | 专业标准 | 校长、中层与教师行为锚点来源 |
| `field-notes/recording-transcript.txt` | 田野材料 | 需求、顾问语言和真实工作流研究 |

新增资料必须归入明确类型目录，并在本索引登记来源、用途和使用边界。不得把下载缓存、临时抽取文本或生成文件提交到这里。

文件版本与完整性指纹见 `SOURCE_MANIFEST.md`。
