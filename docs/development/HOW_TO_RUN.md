# 怎么把工作台跑起来

写给顾问看的。照着做就行，不需要懂技术。

---

## 一、启动

打开「终端」，把下面这一行整个复制进去，回车：

```bash
cd ~/zero/WorkSpace/school-workbench && pnpm dev
```

等十几秒，会自己弹出一个窗口，标题是「学校变革陪跑工作台」。

**这个终端窗口不要关**。关了应用就跟着关了。用完想退出，回到终端按 `Control + C`。

---

## 二、先确认 AI 助手能用

左边点「设置」，中间有一栏叫**默认 AI 助手**，里面写着 **Codex**，已经是选中的。

**这里没有「不用 AI」这个选项**，因为新的分析本来就是 AI 助手做的事：读这所学校已有的材料、对照你认可的判断标准、找相反证据、再整理出一条待你确认的判断。工作台自己不下判断，也不会替它凑一条。

如果 Codex 那一行下面写着「这台电脑上还没有装好 Codex」，说明这台机器上还缺东西。这时候：

- 已经建好的学校、已经确认过的判断、学校状态，**都还能照常打开看**；
- 但**不能开始新的分析** —— 工作台里那个输入框会是灰的，旁边写着「现在还不能开始新的分析」。

装好 Codex、重新启动一次工作台，就恢复了。

---

## 三、日常怎么用

**先说一件事，免得白等**：AI 要下判断，得先知道这所学校现在处在哪个阶段 —— 阶段是它对照着看变化的那把尺子。所以一所学校在「当前阶段」确认下来之前，AI 不会直接给判断，而是先帮你把阶段定下来。

- **全新学校**：直接说一条情况。AI 读过你写的之后，会提议一个「当前阶段」（卡片上是「我理解这个学校目前大致处于……这样理解基本对吗？」）。点「基本对」，阶段就定下来了，后面的用法跟下面写的一样。
- **已经在跟的学校**：阶段早就确认过，直接说情况就行，AI 会按当前阶段来对照。

### 1. 建一所学校

左边点「学校」→ 右上角「新建学校」→ 填名字 → 「创建」。

只需要填名字，别的都不用。建完直接进学校，按下面「说一条最近发生的情况」走一遍就行 —— 第一次说的情况会先帮这所学校定下当前阶段。

### 2. 说一条最近发生的情况

进到学校里，第一栏就是「今天有什么新的情况？」。

直接用大白话写，比如：

> 今天的中层会议里，任务拆解还是主要由校长完成。

写完点「提交情况」。

### 3. 等一会儿

你会看到一行字在变，它按 AI 实际在做的事显示下面这几句里的一句：

```
正在理解学校现在的情况……
正在寻找相关材料……
正在比较最近变化……
正在整理需要你确认的判断……
```

**不一定四句都出现**，也不会往回跳——它做到哪一步就显示哪一句，跳过的那句说明它这一轮没走那一步。

**这一步大概要三到五分钟**，属于正常。屏幕上只会显示这几句，不会有别的东西。

### 4. 确认判断

跑完会出现一张卡片：

```
我发现一个新的情况，想让你确认

中层目前愿意承担任务，但关键任务的拆解仍明显依赖校长。

这个阶段原本希望：中层开始独立完成任务转译。

依据 4 条 · 有 1 条相反迹象

[认同] [我想改一下] [先补充更多依据] [不认同]
```

想看它凭什么这么说，点「为什么这样判断？」，会展开：它看到的事实、这些事实可能说明什么、支持的依据（写明每一条是从哪份材料来的）、与判断不一致的依据、还有哪些可能的解释、目前还不能确定什么、它认为背后的机制、下一轮值得重点观察什么、建议的行动和怎么验证行动有没有用，最后是这条判断的出处（哪所学校、哪个阶段目标、用的是哪一份判断标准的哪一版）。

**这一步只有你说了算。** 不点「认同」，这条判断就永远不会进入这所学校的正式记录 —— AI 自己没有权限确认任何东西。

- **认同** —— 记进去
- **我想改一下** —— 先写下你觉得哪里不准确，再写你的说法。原来那条、你的意见、最终文字都会一起留着
- **先补充更多依据** —— 先放着，不进正式记录
- **不认同** —— 丢掉

### 5. 看这所学校的状态

学校名字下面有「学校状态」，里面是五个方面的当前判断，以及和上一次相比有什么变化。

## 四、遇到问题怎么办

### 提交完没有出现判断卡片

先看学校名字下面有没有「当前阶段」那一块，两种情况处理方式完全不同。

**情况一：这是所全新学校，还没有「当前阶段」。** 第一次说情况时，AI 会先提议一个「当前阶段」，界面上出现「我理解这个学校目前大致处于……这样理解基本对吗？」，点「基本对」确认后，再重新说一条情况，才会出判断。如果那轮跑完没有出现阶段建议，多半是它认为手上的材料还不足以提议阶段 —— 补一点可核实的材料（比如某个具体场合里实际发生了什么）再试。

**情况二：有「当前阶段」，显示「目前依据不足，暂不形成判断」。** 这才是真的材料不够，而且**是正常的，不是出错**。刚开始用的时候会经常遇到 —— 你只说了一句话，它手里就只有这一句，按它那套判断标准，一句转述不足以支撑一条正式判断，所以它选择先不下结论。

它下面会写清楚还缺什么、下一步值得补充什么。**这恰恰是它该有的样子** —— 宁可说不知道，也不硬编一个听起来很像样的判断。

这两种情况工作台都不会替它另外整理一条判断出来。想让它真正给出判断，通常需要更多可核实的材料 —— 比如同一件事在不同时间、不同人身上的观察，而不只是一次转述。

### 出现「AI 助手这次没能完成」

**你写的那句话还在输入框里**，旁边的按钮会变成「重试」，点一下就再来一次。

工作台这时候不会替它写一条判断 —— 没有依据的判断不如没有。

如果一直这样，看下一条。

### 一直连不上 AI

多半是 Codex 还没登录。在终端里跑：

```bash
codex login
```

按提示登录完，回到工作台重新说一条情况试试。

### 出现「现在还不能开始新的分析」

这台电脑上缺 Codex。已经记录下来的东西都还能看，只是不能开始新的分析。装好 Codex，重新启动一次工作台就好了。

### AI 看着很聪明，但我不认可它的判断标准

左边「设置」→「高级设置」→「方法论内容审核」，里面是它用来做判断的那套标准，一条一条列着。

你可以把某一份标记成**「需要修订」**。标了以后，AI 就不能再拿这份标准去下判断了 —— 它会直接停手，而不是换一套说法糊弄过去。改回「可以使用」就恢复。

### 窗口卡住了 / 想重来

回到终端按 `Control + C`，再跑一次第一步那行命令。**你的学校数据都在这台电脑上存着，不会丢。**

---

## 五、几件值得知道的事

- **学校数据存在你这台电脑上**。不过你提交的情况会交给 Codex 去分析，那一步会经过 Codex 自己的服务，不完全留在本机 —— 涉及敏感内容时请自行斟酌
- **AI 不能替你拍板**。它只能整理出「待你确认」的判断，最后点头的永远是你
- **AI 说的每条判断都要有出处**。它必须引用这所学校真实的材料和你认可的判断标准，编不出来
- **新的分析必须有 AI 助手**。它用不了的时候，工作台只能给你看已经记录下来的东西，不会自己顶上去下判断
