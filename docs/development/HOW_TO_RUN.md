# 怎么把工作台跑起来

写给顾问看的。照着做就行，不需要懂技术。

---

## 一、启动

打开「终端」，把下面这一行整个复制进去，回车：

```bash
cd ~/zero/WorkSpace/school-workbench && pnpm dev
```

等十几秒，会自己弹出一个窗口，标题是「学校变革陪跑工作台」。

**这个终端窗口不要关**。关了应用就跟着关了。用完想退出，回到终端按 `Control + C`。

---

## 二、第一次打开，先做一件事：选 AI 助手

左边点「设置」，中间有一栏叫**默认 AI 助手**，两个选项：

- **Codex** —— 选它，你之后每说一条情况，AI 都会先去看一遍这所学校的资料，再给你一条有依据的判断
- **暂不使用 AI 助手** —— 工作台照常记录你说的话，只是不等 AI

**建议先选 Codex。**

选完就不用再管了，以后不会再问你。想改随时回来改。

如果 Codex 那一行下面写着「这台电脑上还没有装好 Codex」，说明这台机器上还缺东西，先选「暂不使用」，工作台照样能用，等装好了再回来改。

---

## 三、日常怎么用

### 1. 建一所学校

左边点「学校」→ 右上角「新建学校」→ 填名字 → 「创建」。

只需要填名字，别的都不用。

### 2. 说一条最近发生的情况

进到学校里，第一栏就是「今天有什么新的情况？」。

直接用大白话写，比如：

> 今天的中层会议里，任务拆解还是主要由校长完成。

写完点「提交情况」。

### 3. 等一会儿（选了 Codex 的话）

你会看到一行字在变：

```
正在理解学校现在的情况……
正在寻找相关材料……
正在比较最近变化……
正在整理需要你确认的判断……
```

**这一步大概要半分钟到两分钟**，属于正常。屏幕上只会显示这几句，不会有别的东西。

### 4. 确认判断

跑完会出现一张卡片：

```
我发现一个新的情况，想让你确认

中层目前愿意承担任务，但关键任务的拆解仍明显依赖校长。

依据 4 条 · 有 1 条相反迹象

[认同] [我想改一下] [先补充更多依据] [不认同]
```

想看它凭什么这么说，点「为什么这样判断？」，会展开它看到的事实、暂时的解释、相反的依据、还不确定的地方。

**这一步只有你说了算。** 不点「认同」，这条判断就永远不会进入这所学校的正式记录 —— AI 自己没有权限确认任何东西。

- **认同** —— 记进去
- **我想改一下** —— 改成你的说法再记
- **先补充更多依据** —— 先放着，不进正式记录
- **不认同** —— 丢掉

### 5. 看这所学校的状态

学校名字下面有「学校状态」，里面是五个方面的当前判断，以及和上一次相比有什么变化。

## 四、遇到问题怎么办

### 提交后出现「AI 助手这次没能完成」

**你说的那句话没有丢**，工作台已经自己整理成一条判断放在下面了，照常确认就行。

AI 那边可以过一会儿再试。如果一直这样，看下一条。

### 一直连不上 AI

多半是 Codex 还没登录。在终端里跑：

```bash
codex login
```

按提示登录完，回到工作台重新说一条情况试试。

### 出现「AI 助手在这台电脑上还没准备好」

这台电脑上缺 Codex。先去「设置」里选「暂不使用 AI 助手」——**工作台的其他功能全都照常能用**，说情况、确认判断、看学校状态都不受影响。等装好 Codex，重新启动一次工作台，再回设置里改回来。

### AI 看着很聪明，但我不认可它的判断标准

左边「设置」→「高级设置」→「方法论内容审核」，里面是它用来做判断的那套标准，一条一条列着。

你可以把某一份标记成**「需要修订」**。标了以后，AI 就不能再拿这份标准去下判断了 —— 它会直接停手，而不是换一套说法糊弄过去。改回「可以使用」就恢复。

### 窗口卡住了 / 想重来

回到终端按 `Control + C`，再跑一次第一步那行命令。**你的学校数据都在这台电脑上存着，不会丢。**

---

## 五、几件值得知道的事

- **所有数据都在你这台电脑上**，没有上传到任何地方
- **AI 不能替你拍板**。它只能整理出「待你确认」的判断，最后点头的永远是你
- **AI 说的每条判断都要有出处**。它必须引用这所学校真实的材料和你认可的判断标准，编不出来
- **不用 AI 也能完整使用**：说情况、确认判断、看阶段、看学校状态，这些从头到尾都不依赖 AI
